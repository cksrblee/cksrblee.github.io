Welcome to my new blog space! I recently migrated this site from **Notion + oopy** to a static site hosted directly on **GitHub Pages**.

## Why Move to GitHub Pages?

- **Full control over layout & speed**: Custom responsive split-view on desktop, clean vertical flow on mobile, and instant static asset loading.
- **No expiring media URLs**: All images and logos now live directly inside the repository.
- **Markdown-first writing**: New posts can be written as simple `.md` files in `posts/` and automatically published on `git push`.

## How a Post Looks

You can write standard Markdown here — headings, lists, links, blockquotes, and code blocks:

```python
def greet(name: str = "Chan") -> str:
    return f"Hello from {name}'s GitHub Pages!"
```
